# Nail Art Generator

Generateur de designs d'ongles par intelligence artificielle. Creez des visuels professionnels de nail art en quelques secondes.

## Fonctionnalites

- Generation de designs de nail art par IA
- Formats optimises pour les reseaux sociaux (Instagram, Pinterest, Facebook, TikTok)
- Templates d'occasions (mariage, fetes, saisons...)
- Generation automatique de multiples designs
- Telechargement et partage facile

## Technologies

- React 19 + TypeScript
- Tailwind CSS
- Vite

## Installation

```bash
npm install
npm run dev
```

## API

Les images sont generees par [pollinations.ai](https://pollinations.ai).
